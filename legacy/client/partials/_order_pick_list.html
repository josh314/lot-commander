There will be an entry below for each seperate lot in the order.
  • The lot's Handle will appear on a barcode label affixed to the lot.
  • If there is no Handle use the Title to identity the lot. "Everyday Bargain" lots, or other orders which may need to be put together at order time, will fall into this category.
  • The Package Type indicates if the lot is packaged in boxes, pallets or truckloads.
  • Some lots may have more than one package: the Total entry will indicate how many packages to look for. In some cases, the Total entry will indicate 'unknown'.
  • To pick a lot, find the barcode matching the Handle and scan it into the Scan Pick Item field above. If the lot is in the picklist, you will hear a success tone and the Scanned field will increase by one for the corresponding entry.
  • Scan each individual package for each lot. When the number Scanned> equals the number Total, the Picked field will change from a red X () to a green check ().
  • Use the yellow Mark as Picked button to manually mark a lot as picked. This should only be necessary if the lot has no Handle to scan. Make sure that all packages belonging to the lot are accounted for.
  • If you make an error, or data has not appeared to load correctly, you can use the red Reset Picklist button above to reset the picking process for the entire order.
